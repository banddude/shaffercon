# Shaffer Construction SEO Business Impact Plan

Last updated: May 5, 2026

## Goal

Grow qualified calls, quote requests, and commercial electrical opportunities from organic search. Traffic matters only when it supports work Shaffer Construction wants to win.

## Current Baseline

Google Analytics is installed and receiving realtime traffic. Search Console is connected.

Recent Search Console snapshot:

1. 616 total web search clicks in the last 3 months.
2. 197,000 total impressions in the last 3 months.
3. 0.3 percent average CTR.
4. 10.8 average position.
5. 531 indexed pages.
6. 2,364 not indexed pages.

Technical audit snapshot:

1. 1,258 sitemap URLs audited.
2. No confirmed 404, canonical, noindex, missing title, missing description, missing H1, or thin content categories.
3. 71 titles longer than 60 characters.
4. 33 descriptions longer than 160 characters.
5. The four audit errors were transient read timeouts and returned 200 on retry.

## Prioritization Rule

Do not optimize every ranking page equally. Score pages by business value first, then SEO opportunity.

Use this score:

`priority = business value x search intent x SEO opportunity x implementation speed`

Business value tiers:

1. Tier 1, direct money pages: commercial EV charging, electrical load studies, commercial service, facilities maintenance, LED retrofit, residential EV charging, panel upgrades, code corrections, troubleshooting, Zinsco panel replacement.
2. Tier 2, high intent support pages: permits, costs, inspections, utility coordination, panel capacity, rebates, code requirements, installation timelines.
3. Tier 3, location pages: pages that match real service areas and can route visitors into Tier 1 services.
4. Tier 4, informational posts: useful for authority and internal links, but lower priority unless Search Console proves they are driving qualified queries.
5. Tier 5, weak traffic: national news, broad informational topics, and terms unlikely to lead to work.

## Execution Order

### Phase 1, CTR Wins on Money Pages

Purpose: capture more clicks from pages already visible in Google.

Actions:

1. Export Search Console data for the last 3 months.
2. Build an opportunity list with URL, query, impressions, clicks, CTR, average position, business tier, intent, and recommended action.
3. Rewrite titles and meta descriptions for Tier 1 pages first.
4. Rewrite above the fold copy for pages with impressions but weak CTR.
5. Add stronger service specific calls to action where the searcher intent is commercial.

2. `/commercial-service/`
3. `/electrical-load-studies/`
4. `/led-retrofit-services/`
5. `/residential-ev-charger/`
6. `/statewide-facilities-maintenance/`

### Phase 2, Query Led Content Expansion

Purpose: create or improve pages around searches that already show demand.

Known query candidates from Search Console:

1. electrical panel upgrade permit los angeles
2. lighting retrofit electrician
3. zinsco panel replacement
4. kitchen outlet spacing
5. electrical final inspection

Actions:

1. Map each qualified query to an existing page if one already exists.
2. Create a new page only when the existing site does not have a good matching destination.
3. Link support pages back to the relevant money page and contact page.
4. Keep content focused on hiring intent, cost, permit path, inspection risk, and what Shaffer needs to quote the job.

### Phase 3, Indexing Cleanup

Purpose: make sure Google spends crawl and indexing attention on pages that matter.

Actions:

1. Export Search Console indexing reasons and affected URLs.
2. Compare excluded URLs against the live sitemap.
3. Classify each excluded URL as old junk, duplicate, redirect needed, low value, or should be indexed.
4. Add redirects for valuable old URLs.
5. Remove or noindex weak duplicates only when they do not serve a business purpose.

### Phase 4, Schema and SERP Enhancements

Purpose: improve eligibility for rich search treatment and strengthen entity clarity.

Actions:

1. Verify FAQ schema coverage on service detail pages, service landing pages, and high intent support pages.
2. Add FAQ schema to landing pages where the visible page has real FAQ content.
3. Audit Service schema for the main money pages.
4. Keep LocalBusiness and Organization schema consistent across the site.

### Phase 5, Measurement

Purpose: optimize for leads, not only sessions.

Actions:

1. Confirm GA4 tracks phone clicks, email clicks, form submits, and CTA clicks.
2. Mark lead events as key events in GA4.
3. Build a simple weekly report: clicks, impressions, CTR, average position, leads, top gaining pages, top opportunity pages.
4. Review Search Console every week and update the opportunity list.

## Work Queue

Immediate queue:

2. Create a Search Console opportunity export or local scoring workflow.
3. Build the first prioritized rewrite list.
4. Rewrite the top five business value pages from that list.
5. Run build, SEO audit, and deploy.

Definition of done for each page:

1. Title is clear, business aligned, and usually under 60 characters.
2. Meta description is under 160 characters and contains a reason to call or request a quote.
3. H1 matches the service and intent.
4. Intro copy answers the searcher quickly.
5. CTA matches the job type.
6. Internal links point to related money pages.
7. Schema is present when the page has eligible content.
8. Page passes build and audit checks.
